# Tanvi Kamble

Portfolio site for Tanvi Kamble, sous chef. A single static page, served with GitHub Pages.

## Files

- `index.html` is the whole site: markup, styles and script in one file.
- `images/` holds the dish photos. `images/route/` holds the photos for each city on the route, named `<city>-<n>.jpg` (for example `sofia-2.jpg`). Replace a file with the same name to swap a photo.
- `tanvi-kamble-resume.pdf` is the resume linked from the nav and the contact section.

## Publishing

Pages serves the `main` branch from the root folder. Any push to `main` updates the live site within a minute or two.
